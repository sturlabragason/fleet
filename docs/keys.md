# Keys

fleet has two sets of keys: the overview TUI's own keys, and tmux bindings that `fleet up` sets on the `fleet` tmux server. The bindings are set with `bind-key -n` on that server only, so your own tmux setup is not touched.

You don't need to remember them: `Alt+?` opens a popup with every key (any key closes it), `?` in the overview shows the same list, and `fleet keys` prints it. All of these, the status-line hint and the table in [DESIGN.md §5](../DESIGN.md#hotkey-hints-and-help-built) come from one registry, [`internal/keys`](../internal/keys/keys.go).

## Mouse

Mouse mode is on inside the fleet window: click a pane to focus and type in it, drag a border to resize, scroll for history, right-click for the tmux menu (Mark sets the `Alt-o` target).

Copying works in the admiral and agent panes:

| Do this | You get |
| --- | --- |
| Drag with the left button | the dragged text on the system clipboard |
| Double-click | that word on the clipboard |
| Triple-click | that line on the clipboard |

The text is on the system clipboard as soon as you let go, so `Ctrl+Shift+V` pastes it straight back into a pane; there is no `Ctrl+Shift+C` step. Fleet takes the left-button drag for tmux even though the agent's own TUI asks for the mouse, which is why selecting works at all here (DESIGN.md ADR-38); clicks, the wheel and the right-click menu still go to the agent. The overview pane is the exception: its cards answer clicks, so dragging there selects nothing.
